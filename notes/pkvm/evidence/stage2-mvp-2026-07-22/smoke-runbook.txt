STEPS
-----
1. Deploy Image+modules via a NON-DEFAULT GRUB entry; keep the stable kernel default
   + bootable. Confirm `uname -r` == 6.6.30+ and the running Build ID == 33774811....
2. Copy the aarch64 syz-executor + syz-execprog (hashes above) and the test file
   sys/linux/test/arm64-syz_kvm_run_fw_fault to N90.
3. On N90, run the smoke pinned to ONE CPU (0), with the pkvm_mem_abort kprobe armed
   so #23 reachability + fault IPA are observed. The debugfs-enable shell AND
   syz-execprog share the affinity so ring owner_cpu == the CPU that runs KVM_RUN:

     T=/sys/kernel/tracing            # or /sys/kernel/debug/tracing
     echo > "$T/kprobe_events"
     echo 'p:fw_abort_in  pkvm_mem_abort ipa=+0(%x1):x64' >> "$T/kprobe_events"
     echo 'r:fw_abort_ret pkvm_mem_abort ret=$retval:s64'  >> "$T/kprobe_events"
     echo 1 > "$T/events/kprobes/fw_abort_in/enable"
     echo 1 > "$T/events/kprobes/fw_abort_ret/enable"
     : > "$T/trace"

     taskset -c 0 sh -ceu '
       echo 1 > /sys/kernel/debug/kvm/pkvm_cov/enable
       test "$(cat /sys/kernel/debug/kvm/pkvm_cov/owner_cpu)" = 0
       trap "echo 0 > /sys/kernel/debug/kvm/pkvm_cov/enable" EXIT
       timeout 30 ./syz-execprog -procs=1 -threaded=0 -vv=1 \
         -coverfile=/tmp/pkvm-el2.raw arm64-syz_kvm_run_fw_fault
     '

     echo "=== pkvm_mem_abort trace (fault IPA + return) ==="; cat "$T/trace"
     echo 0 > "$T/events/kprobes/fw_abort_in/enable"
     echo 0 > "$T/events/kprobes/fw_abort_ret/enable"
     echo > "$T/kprobe_events"     # cleanup
   FLAG/OUTPUT notes (these were the runbook gaps):
   - -procs=1 -threaded=0 is what serializes. -collide is a no-op in this syzkaller.
   - -vv=1 is REQUIRED to see the per-call result line ("CALL ... errno ..."); a
     helper FAILURE does NOT make syz-execprog exit non-zero -- read the line and
     confirm call 1 errno 0 yourself.
   - -coverfile is a PREFIX. The program is prog1:
       /tmp/pkvm-el2.raw_prog1.0  = call 0 (openat$kvm)
       /tmp/pkvm-el2.raw_prog1.1  = call 1 (syz_kvm_run_fw_fault)  <-- EL2 coverage here
     Each line is one hex PC, ALREADY PreviousInstructionPC-adjusted (call site).
   - The outer `timeout` + GWDT are the hang net (the helper has no alarm()); a killed
     worker => coverage never returns => smoke FAILURE, never a faked pass.

4. Symbolize on the HOST with the SAME vmlinux, using the COMMITTED cfg (its
   kernel_obj/kernel_src point at the isolated tree; the stable workdir/pkvm-arm64.cfg
   points at /home/jose/common and would mis-symbolize):
     scp N90:/tmp/pkvm-el2.raw_prog1.1 .
     ./bin/syz-cover \
       -config=notes/pkvm/evidence/stage2-mvp-2026-07-22/pkvm-stage2-smoke.cfg \
       ./pkvm-el2.raw_prog1.1
   (syz-cover symbolizes the hex PCs against kernel_obj's vmlinux; it does NOT re-apply
   PreviousInstructionPC, so the already-adjusted call sites resolve correctly.)

ACCEPTANCE (ALL required; any miss = FAIL -- do not call it a pass)
------------------------------------------------------------------
- syz-execprog -vv=1 shows call 1 (syz_kvm_run_fw_fault) errno 0 (clean KVM_EXIT_MMIO).
- owner_cpu == 0 (the taskset CPU).
- kprobe trace: first fw_abort_in ipa == 0x7fc00000 and fw_abort_ret ret == 0.
- /tmp/pkvm-el2.raw_prog1.1 is non-empty and has >= 1 __kvm_nvhe_-range PC.
- syz-cover (same vmlinux) maps >= 1 such PC to a Rust rust/src/.../*.rs:line.
- dmesg has NONE of: "CPU != owner", "ring overflow", "teardown unconfirmed",
  "unshare unconfirmed", WARN, BUG. (The kvm_main.c revert restores the
  duplicate-debugfs-directory pr_warn, so dmesg is a real signal again.)
- after the run, disable prints the real "pkvm_cov: ring disarmed".

IF IT FAILS -- classify by symptom BEFORE changing code
-------------------------------------------------------
- #23 reached (kprobe fired) but no EL2 PC:  ring enable / CPU affinity / HVC setup.
- EL2 PC present but no .rs:line:             runtime->link conversion or same-build symbolization.
- owner-CPU skip in dmesg:                    affinity not closed (shell vs execprog different CPU).
- overflow (or count==511):                   KEEP the result; assess ring capacity; NOT complete coverage.
