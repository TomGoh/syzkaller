STEPS
-----
1. Deploy Image+modules via a NON-DEFAULT GRUB entry; keep the stable kernel default
   + bootable. Confirm `uname -r` == 6.6.30+ and the Build ID matches.
2. Copy the aarch64 syz-executor + syz-execprog (hashes above) and the test file
   sys/linux/test/arm64-syz_kvm_run_fw_fault to N90.
3. Pin ONE CPU (0). The debugfs-enable shell AND syz-execprog must share the affinity
   so the ring owner_cpu == the CPU that runs KVM_RUN:

     taskset -c 0 sh -ceu '
       echo 1 > /sys/kernel/debug/kvm/pkvm_cov/enable
       test "$(cat /sys/kernel/debug/kvm/pkvm_cov/owner_cpu)" = 0
       trap "echo 0 > /sys/kernel/debug/kvm/pkvm_cov/enable" EXIT
       timeout 30 ./syz-executor exec_prog ... ; # (or:)
       timeout 30 ./syz-execprog -procs=1 -threaded=0 -vv=1 \
         -coverfile=/tmp/pkvm-el2.raw arm64-syz_kvm_run_fw_fault
     '
   NOTES on the flags/output (these were the runbook gaps):
   - -procs=1 -threaded=0 is what serializes. -collide is a no-op in this syzkaller.
   - -vv=1 is REQUIRED to see the per-call result line ("CALL ... errno ..."); without
     it there is no errno print. A helper FAILURE does NOT make syz-execprog exit
     non-zero -- you MUST read the -vv line and confirm call 1 errno 0 yourself.
   - -coverfile is a PREFIX. Output is per (program,call): the program is prog1, so
       /tmp/pkvm-el2.raw_prog1.0  = call 0 (openat$kvm)
       /tmp/pkvm-el2.raw_prog1.1  = call 1 (syz_kvm_run_fw_fault)  <-- EL2 coverage here
     Each line is one hex PC, ALREADY PreviousInstructionPC-adjusted (call site).
   - The outer `timeout` + GWDT are the hang net (the helper has no alarm()); a killed
     worker => this run's coverage never returns => smoke FAILURE, never a faked pass.

4. Symbolize on the HOST with the SAME vmlinux (dedicated cfg points kernel_obj/src at
   the isolated tree -- the stable workdir/pkvm-arm64.cfg points at /home/jose/common
   and would mis-symbolize):
     scp N90:/tmp/pkvm-el2.raw_prog1.1 .
     ./bin/syz-cover -config=workdir/pkvm-stage2-smoke.cfg ./pkvm-el2.raw_prog1.1
   (syz-cover reads the hex PCs and symbolizes against kernel_obj's vmlinux; it does
   NOT re-apply PreviousInstructionPC, so the already-adjusted call sites are correct.)

ACCEPTANCE (ALL required; any miss = FAIL -- do not call it a pass)
------------------------------------------------------------------
- syz-execprog -vv=1 shows call 1 (syz_kvm_run_fw_fault) errno 0  (clean KVM_EXIT_MMIO).
- owner_cpu == 0 (the taskset CPU).
- first guest fault at ipa 0x7fc00000, pkvm_mem_abort ret 0 (kprobe, as in the earlier
  firmware smoke).
- /tmp/pkvm-el2.raw_prog1.1 is non-empty and contains >= 1 __kvm_nvhe_-range PC.
- syz-cover (same vmlinux) maps >= 1 such PC to a Rust rust/src/.../*.rs:line.
- dmesg has NONE of: "CPU != owner", "ring overflow", "teardown unconfirmed",
  "unshare unconfirmed", WARN, BUG. (The kvm_main.c revert restores the
  duplicate-debugfs-directory pr_warn, so dmesg is a real signal again.)
- after the run, disable prints the real "pkvm_cov: ring disarmed" (not just echo 0
  returning success).

IF IT FAILS -- classify by symptom BEFORE changing code
-------------------------------------------------------
- #23 reached but no EL2 PC:       ring enable / CPU affinity / HVC setup.
- EL2 PC present but no .rs:line:   runtime->link conversion or same-build symbolization.
- owner-CPU skip in dmesg:          affinity not closed (shell vs execprog different CPU).
- overflow (or count==511):         KEEP the result; assess ring capacity; do NOT call
                                    it complete coverage.
